# Mistura e masterização

Aqui ficam os MP3 dos trabalhos de mistura. Cada trabalho tem dois ficheiros: `-antes` e `-depois` (por exemplo `nome-antes.mp3` e `nome-depois.mp3`).
As duas versões devem ter exatamente a mesma duração e começar no mesmo ponto, para a comparação Antes/Depois ficar alinhada.
Para acrescentar: **Add file** → **Upload files**, arrasta os MP3 e clica em **Commit changes**.
Nomes: só MP3, em minúsculas, sem espaços nem acentos. Mais explicações no [README principal](../../README.md).
