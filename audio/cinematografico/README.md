# Áudio cinematográfico

Aqui ficam os MP3 do teu áudio cinematográfico.
Para acrescentar: abre esta pasta no GitHub, clica em **Add file** → **Upload files**, arrasta os MP3 e clica em **Commit changes**.
O nome do ficheiro: só MP3, em minúsculas, sem espaços nem acentos (por exemplo `curta-metragem.mp3`).
Depois indica o ficheiro no `conteudo.js`. Mais explicações no [README principal](../../README.md).
