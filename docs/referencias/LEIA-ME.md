# Referências visuais aprovadas

Ficheiros de consulta para quem implementa o site. Não são publicados e não fazem parte do código.

- `design-b.dc.html` — mockup aprovado do design B (página completa). Contém os estilos em linha: tamanhos, espaços, linhas e tipos de letra. Está no formato do editor de design (`<x-dc>`, `{{...}}`): lê-se como HTML, não se abre como página.
- `leitor-prototipo.html` — protótipo com som, a opção 2 (Completa) é a aprovada. Abre-se no browser (precisa de rede para as fontes). O código de desenho da forma de onda, do espectro e do campo estéreo e o CSS do painel são o ponto de partida do `js/instrumentos.js` e do `estilo.css`. As opções 1 e 3, o sinal de teste sintetizado e o gancho `window.__leitor` não passam para o site.

Mockup original (privado): https://claude.ai/artifact/VyWxEc2S4zVYcwpyzY8b7a
Protótipo original (privado): https://claude.ai/artifact/WUthhU6paP255s8PQaRMNU
